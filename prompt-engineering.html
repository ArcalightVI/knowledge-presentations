Cómo hablar correctamente con la IA:
Introducción al Prompt Engineering

Diapositiva 1

¿Qué es Prompt Engineering?

Un prompt es la instrucción que le damos a una inteligencia artificial.

El Prompt Engineering es el proceso de diseñar esas instrucciones para obtener mejores resultados.

La calidad de la respuesta de una IA depende principalmente de tres cosas:

  • 🎯 Qué tan claro es el prompt
  • 📚 Cuánta información tiene la IA
  • 💬 Cómo está estructurada la conversación
Muchas veces la IA falla no porque el modelo sea malo, sino porque la instrucción es mala o incompleta.
Diapositiva 2

El mayor error al usar IA

Muchas personas usan herramientas como:

ChatGPT Gemini Grok

haciendo preguntas demasiado simples.

Ejemplo típico:

Haz un reporte.

El problema es que la IA no sabe:

  • el contexto
  • el objetivo
  • el nivel de profundidad
  • el formato esperado

Por eso muchas respuestas parecen genéricas o poco útiles.

Diapositiva 3

Los 4 elementos de un buen prompt

Un buen prompt normalmente tiene cuatro componentes:

1. Rol

Qué tipo de experto debe simular la IA.

Ejemplo: Actúa como analista financiero.
2. Contexto

Información que ayuda al modelo a entender el problema.

Ejemplo: Considera el mercado latinoamericano.
3. Tarea

Lo que realmente queremos que haga.

Ejemplo: Analiza las principales tendencias del sector.
4. Formato

Cómo queremos la respuesta.

Ejemplo: Resume el resultado en una tabla.
Diapositiva 4

Ejemplo de prompt completo

❌ Prompt simple:

Analiza el mercado tecnológico.

✅ Prompt estructurado:

Actúa como analista de mercado. Analiza tres tendencias tecnológicas que afectarán a América Latina en los próximos cinco años. Resume el resultado en una tabla.

El segundo prompt produce una respuesta mucho más clara y útil.

Diapositiva 5

La memoria de la IA: tokens

Las IAs no leen texto como los humanos.
Primero convierten todo en tokens.

Un token es una pequeña unidad de texto. Puede ser: una palabra, parte de una palabra, o un símbolo.

Ejemplo:

Fotografía puede dividirse en tokens como:

foto — graf — ía
Diapositiva 6

Por qué los tokens son importantes

Los modelos tienen un límite de tokens por conversación.

Ese límite incluye:

1 lo que escribimos
2 lo que responde la IA
3 todo el historial del chat

Cuando ese límite se llena ocurren varios problemas.

Diapositiva 7

Qué pasa cuando la memoria se llena

Cuando una conversación tiene demasiados tokens pueden ocurrir varios problemas:

  • ⚠️ La IA empieza a olvidar información del inicio del chat.
  • ⚠️ Las respuestas se vuelven menos coherentes.
  • ⚠️ El modelo mezcla contextos distintos.
  • ⚠️ La calidad de las respuestas disminuye.

Esto muchas veces se describe como:

corrupción del contexto.

Diapositiva 8

Error común: usar el mismo chat para todo

Muchas personas usan un mismo chat durante días o semanas para cualquier tema.

Ejemplo: Mi Chat Único
preguntas de programación
luego...
marketing
luego...
temas personales
luego...
análisis financiero
Esto genera demasiados contextos mezclados.
Diapositiva 9

Buena práctica

Cuando el tema cambia, es mejor crear un chat nuevo.

Ejemplo:

Chat 1 → programación
Chat 2 → marketing
Chat 3 → análisis de mercado

Esto mejora considerablemente la calidad de las respuestas.

Diapositiva 10

Otro problema: los falsos expertos en IA

En redes sociales han aparecido muchos "gurús de inteligencia artificial".

Muchos de ellos:

  • repiten información superficial
  • comparten prompts virales
  • exageran capacidades de la IA

La realidad es que usar bien la IA no depende de copiar prompts de internet.

Depende de entender:

  • 💡 cómo funciona el modelo
  • 🧩 cómo estructurar instrucciones
  • 🎯 cómo darle contexto adecuado.
Diapositiva 11

Ejemplos reales

Mal prompt vs buen prompt

Una de las mejores formas de entender el Prompt Engineering es comparar ejemplos.

Ejemplo 1 — Explicación

❌ Prompt típico

Explícame la inteligencia artificial.

Problema: demasiado general.

✅ Prompt mejorado

Actúa como profesor de tecnología. Explica qué es la inteligencia artificial para personas sin conocimientos técnicos usando ejemplos simples.

Ejemplo 2 — Trabajo empresarial

❌ Prompt simple

Haz una estrategia de ventas.

El modelo no sabe: qué producto, qué mercado, qué clientes.

✅ Prompt mejorado

Actúa como consultor de ventas B2B. Diseña una estrategia para vender software empresarial a empresas medianas en Latinoamérica. Incluye tres estrategias principales y sus riesgos.

Ejemplo 3 — Redacción de contenido

❌ Prompt básico

Escribe un post sobre inteligencia artificial.

Resultado: contenido genérico.

✅ Prompt estructurado

Actúa como especialista en marketing tecnológico. Escribe un post de LinkedIn de 150 palabras sobre cómo la inteligencia artificial está cambiando el trabajo en las empresas.

Ejemplo 4 — Análisis de información

❌ Prompt descuidado

Resume este texto.

✅ Prompt mejorado

Resume este texto en cinco puntos clave orientados a ejecutivos que necesitan entender las implicaciones estratégicas del contenido.

Diapositiva 12

Técnicas simples de Prompt Engineering

Tres técnicas que mejoran mucho los resultados.

1. Pedir razonamiento paso a paso

Esto ayuda al modelo a analizar problemas complejos.

Ejemplo: Explica tu razonamiento paso a paso.

2. Dividir problemas grandes

En lugar de pedir todo en una sola pregunta:

Haz un plan completo de marketing.

Mejor dividirlo en partes.

3. Usar ejemplos

Los modelos funcionan muy bien con ejemplos.

Ejemplo: Usa el siguiente formato como referencia para responder.
Diapositiva 13

El Prompt Maestro

Existe una estructura que funciona bien en la mayoría de situaciones.

Estructura

Rol + Contexto + Tarea + Formato + Nivel de detalle
Diapositiva 14

Plantilla del Prompt Maestro

Puedes usar esta estructura:

Actúa como [rol o experto]

Contexto: [explica la situación o problema]

Tarea: [lo que quieres que haga la IA]

Formato: [cómo quieres la respuesta]

Nivel de profundidad: [básico, intermedio o experto]

Diapositiva 15

Ejemplo usando el Prompt Maestro

Consulta simple:

Explícame blockchain.

Prompt maestro aplicado:

Actúa como profesor de tecnología.

Contexto: estoy aprendiendo sobre tecnologías emergentes.

Tarea: explica qué es blockchain y cómo funciona.

Formato: usa ejemplos simples y divide la explicación en cinco puntos.

Nivel de profundidad: básico.

Diapositiva 16

Buen hábito al usar IA

Antes de enviar un prompt haz tres preguntas:

¿Le di suficiente contexto a la IA?

¿Definí claramente lo que quiero?

¿Especifiqué cómo quiero la respuesta?

Si la respuesta es sí, el resultado será mucho mejor.

Diapositiva 17

Conclusión

La inteligencia artificial es una herramienta extremadamente poderosa.

Pero la calidad de los resultados depende de cómo la usamos.

Las personas que obtendrán más valor de la IA serán quienes aprendan a:

  • ✓ estructurar preguntas
  • ✓ proporcionar contexto
  • ✓ trabajar con el modelo de forma iterativa

En otras palabras:

la habilidad del futuro no será solo usar IA, sino saber conversar con ella.
